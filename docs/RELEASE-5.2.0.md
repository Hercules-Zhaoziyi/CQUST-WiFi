## v5.2.0 · 边框修复与桌面代理

### 窗口与关于页

- 移除吸附动画反复设置原生裁剪区域的方式，修复拖离后边框残留；增加原生边框与裁剪状态回归检查。
- 吸附默认关闭。旧版升级后一次性关闭吸附，之后可按需手动开启。
- 关于页新增“加入内测群”，连接作者提供的 QQ 群入口；“软件介绍与下载”改为“软件介绍”。

### 桌面代理（默认关闭）

- “常用网站”后新增代理页，支持 HTTP 转发、HTTPS CONNECT、SOCKS5 TCP 与 UDP ASSOCIATE，可选混合端口。
- 默认仅本机监听；自己的其他设备需连接时，可手动开启局域网访问。无需填写客户端 IP 白名单。
- 强制使用独立的代理用户名和密码：自定义 8–64 位密码，或一键推荐 12 位易输入密码。不使用校园网密码，不写入配置或日志。
- 显示地址、端口、连接数及流量，支持复制；关闭后停止监听并断开已有转发，重启不会自动恢复。
- 不改系统代理或防火墙，不解密 HTTPS，不提供透明代理、TUN / VPN 或 Android 应用。

### 下载及边界

本次提供 **Windows x64 安装包**与对应源码；保留 macOS 源码支持，但未在 Mac 上构建或验证 v5.2.0。Mac 用户可继续使用历史 v5.1.1 安装包。

代理仅供自己的设备在可信网络中显式配置使用。HTTP Basic / SOCKS5 认证本身不加密；客户端互访、防火墙、账号权限及网络规则可能阻止使用。不会修改校园网认证或设备配额；不保证任何网络下均可连通。

升级前请从托盘退出旧版。安装器未数字签名；提供 `SHA256SUMS.txt` 校验值。

验证：24 项 Rust 离线测试与 78 项 Tauri 隔离窗口检查通过。仅在本机 loopback 测试代理，不中断真实校园网会话；校园网跨设备连通性仍需现场验证。
