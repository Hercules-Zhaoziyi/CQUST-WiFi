# 桌面端显式代理（v5.2.1）

代理是可选的桌面端转发服务，默认关闭，重启软件后也不会自动恢复。

## 使用

1. 在“常用网站”后的“代理”页选择 HTTP、SOCKS5 或混合协议。默认端口 7890。
2. 用户名留空使用当前校园网账号，也可自定义。密码默认由后台复用校园网密码，不传回界面、不显示、不复制。未取得时先登录，或选择自定义密码。自定义密码为 8–64 位可见英文字符，默认可见，可以用小眼睛隐藏；推荐密码为 12 位随机字符。
3. “允许局域网设备连接”默认打开，代理服务仍默认关闭。本机使用可关闭局域网选项。无需填写客户端 IP。
4. 在客户端填写桌面端显示的 IPv4、端口、用户名和密码。HTTPS 使用 HTTP CONNECT；SOCKS5 支持 TCP CONNECT 与 UDP ASSOCIATE。
5. 关闭代理会停止监听并断开现有转发。改变地址、端口、协议或密码前先关闭代理。连接不同网络后，重新启用并确认显示的新地址。

## 防火墙与连接链接

Windows 可能记住首次取消或拒绝的结果，反复启用不保证再次弹窗。“重新打开防火墙设置”仅打开系统允许应用页面，由用户确认管理员权限并核对程序路径、允许当前网络类型。校园网可能属于公用网络。若有阻止规则，请核对高级入站规则或联系网络管理员；不要关闭整个防火墙。macOS 打开系统防火墙页面。应用不自动修改规则；启动成功不等于防火墙已放行。

SOCKS5 链接为 `socks5://服务器:端口`，HTTP 链接为 `http://服务器:端口`，不包含密码；凭据需单独填写。兼容客户端支持 `socks5h://` 服务端域名解析。HTTPS 使用 CONNECT，不是 TLS 加密的 HTTPS 代理服务器。未添加缺少密码认证的 SOCKS4。

## 范围与限制

- 实现标准显式转发，不使用 Clash 内核，不复制其实现；不含订阅、分流规则、TUN、透明代理、系统代理设置。
- 仅本机模式绑定 `127.0.0.1`；局域网模式只绑定当前路由对应的私有 IPv4 地址，不绑定所有网卡，不自动创建防火墙放行规则。
- 局域网源地址不设具体 IP 白名单，避免移动接入点导致客户端 IP 变化。必须通过 HTTP Basic 或 SOCKS5 用户名/密码认证；不会提供免认证代理。
- HTTP Basic 与 SOCKS5 认证自身不加密，请仅在可信网络与自己的设备中使用；HTTPS 隧道不会被解密。密码只保留在本次运行内存中，不写日志或设置文件。复用校园网密码会增加凭据泄露风险，推荐使用独立代理密码。
- 最多 64 个并发会话，握手限时 10 秒，单会话最多 1 小时。UDP 关联跟随已认证的 TCP 控制连接关闭；不接受 UDP 分片和未请求的远端回复。
- 目标域名在服务端解析并检查实际地址，拒绝本机、私有网段、链路本地、组播、保留地址及邮件发送端口，避免将代理用于访问设备管理面或邮件滥发。TCP/UDP 只访问允许的公网目标。
- 不修改校园网认证协议或设备配额。校内客户端隔离、防火墙及账号服务规则可能阻止连接，能够 ping 通不代表代理端口一定可达。请遵守学校网络规则。

## 验证

Rust 测试使用仅测试构建可访问的 loopback 目标，检查 HTTP 转发及凭据剥离、CONNECT 不透明字节转发、SOCKS5 TCP/UDP、错误认证拒绝、服务关闭和密码校验。正式构建不存在此 loopback 目标例外。本次不为测试注销真实校园网，也不让真实局域网客户端连接。
