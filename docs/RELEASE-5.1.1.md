## v5.1.1 · 贴边收起与 Markdown 更新简介

### 窗口吸附

- 拖到屏幕工作区边缘后自动收起，保留一条可悬停的边缘。
- 鼠标移到边缘时平滑滑出，拖离边缘即可解除吸附。
- 关闭吸附、托盘恢复和调整高度时恢复可见位置，避免窗口卡在屏外。
- 跟随“界面动效”选项；关闭动效时即时定位。

### 更新检测

- 更新检测回到**设置页底部**。
- 更新简介支持 Markdown 标题、列表、代码块、表格和链接。
- 本地解析并净化内容，不执行脚本、不加载远程图片，HTTP(S) 链接通过系统浏览器打开。

- `CQUST-WiFi-5.1.1-Tauri-Setup.exe`：Windows x64 安装包。
- `CQUST_Wifi_Tauri_v5.1.1_Source.zip`：完整对应源码、本地资源及依赖许可证。
- `SHA256SUMS.txt`：安装包和源码包的 SHA-256 校验值。
