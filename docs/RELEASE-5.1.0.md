## v5.1.0 · 自动发现与桌面体验

### 认证入口自动发现

- 普通 HTTP / HTML 跳转探测失败时，使用隔离的 WebView2 执行校园网页的动态跳转，获取当前完整认证地址后，再由 Rust 重新读取页面、服务和公钥。
- 切换账号不再清空同网络的进程内入口提示；网络 IP 改变或软件退出后失效。不会直接使用旧 userIndex、旧密文或旧公钥提交登录。
- 自动发现确实失败时仍提供官方页面入口和手动填入指引；验证码继续由用户亲自填写，不绕过认证策略。

### 界面与功能

- 修复密码输入框同时出现 WebView2 默认眼睛和应用眼睛的问题。
- 新增默认开启、设置中可即时关闭的窗口吸附：拖动结束后靠近屏幕工作区边缘自动贴边，保持固定窄窗口大小，支持多显示器 / DPI。
- **设置页最顶部**新增 GitHub 更新检测，显示正式新版本号、更新说明与下载按钮；不会静默安装或运行下载内容。
- 关于页链接下方新增“软件介绍与下载”：https://cqust-wifi.ziyis.cn/ 。

### 下载

- `CQUST-WiFi-5.1.0-Tauri-Setup.exe`：Windows x64 安装包。
- `CQUST_Wifi_Tauri_v5.1.0_Source.zip`：对应源码与本地资源。
- `SHA256SUMS.txt`：安装包和源码校验值。

升级前请从系统托盘菜单完全退出旧版。安装器未签名；需要微软 WebView2 运行时，安装器提供缺失时安装方式。

### 验证边界

15 项 Rust 单元测试、1 项 GitHub 最新正式版只读网络测试和 56 项真实 Tauri/WebView2 隔离窗口检查通过。覆盖动态 JS 拼接地址、窗口吸附开启/关闭、更新检测界面和原有登录/验证码交互。

使用隔离的虚构账号进行界面、动态跳转与吸附测试；没有中断当前真实校园网会话，也没有用其他真实账号试登。因此不能把自动化检查等同于所有账号、所有校园网络环境均已实测通过。

本项目为非学校官方工具。请勿在 Issue 中公开账号密码、验证码、Cookie、完整认证网址或 userIndex。
