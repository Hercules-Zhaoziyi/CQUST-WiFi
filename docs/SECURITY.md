# 安全说明

仅在有权限的学校校园网和本人账号下使用。不要绕过校园网认证策略或验证码。

- 凭据写入 Windows 凭据管理器或 macOS 钥匙串，不把真实账号、密码、完整认证 URL、Cookie、验证码或在线会话索引提交到 Git。
- 认证入口提示仅在当前进程内、同一局域网 IP 下用于重新探测；网络地址改变或进程结束后失效。退出账号清除会话和密码，但不再清除入口提示。密码处理方式、公钥与服务仍从重新获取的页面读取。
- 失败时使用不可见、无痕系统 WebView 跟随动态跳转，只允许学校认证地址及指定的无凭据网络探测入口。不传入账号密码、不读取系统浏览器数据，探测结束销毁窗口；远程探测页不能调用主窗口命令。
- 更新检测只读公开 GitHub 正式版 API，不使用 GitHub 令牌；v5.1.1 起使用本地 Marked 与 DOMPurify 按严格允许列表渲染 Markdown，移除脚本、样式、图片和不安全链接。说明链接仅允许 HTTP(S)，通过系统浏览器打开；下载地址限制在本仓库。不静默安装或执行 EXE。
- 第三方网页由系统浏览器打开；应用不读取浏览器已有登录凭据。
- v5.2.0 的显式代理默认不监听，局域网访问需另外手动开启，并强制 HTTP Basic / SOCKS5 用户名密码认证。客户端不设具体 IP 白名单；仅接受本机或私有 IPv4 源地址。认证密码只在内存中保留，不使用校园网密码，不自动放行防火墙，不恢复上次监听。代理认证本身不加密，仅用于可信网络中的本人设备。
- 代理目标先解析再检查，拒绝本机、私网、链路本地及保留地址等目标；UDP 只接受已认证 TCP 关联对应的客户端数据和已请求的远端回复。限制握手时间、会话数量及最长会话时间。参见 [代理说明](PROXY.md)。
- 分享故障时只提供去标识化的错误类型与版本号。请勿上传 `%APPDATA%` 或 macOS Application Support 配置、系统凭据导出、浏览器网络 HAR、带查询参数的认证页面截图或完整认证网址。

本次发布检查了已知原始校园账号配置值，以及常见 GitHub 令牌和私钥模式；解包检查历史安装器及 PyInstaller 成员，没有执行历史软件。源码 ZIP 移除了配置实例、缓存和重复 EXE；软件作为独立 Release 附件提供。

检查不能保证没有所有未知问题或第三方依赖风险。安装包目前未签名，可使用每个 Release 的 SHA256SUMS.txt 检查下载完整性。

本次测试使用隔离账号和测试网络数据，未对真实校园账号做自动断开/登录测试。发现疑似敏感信息时，请先私下联系作者，不要在公开 Issue 传播内容。
