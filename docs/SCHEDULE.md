# 课程表（v5.2.2 起）

课程表是可选的本地查看功能，默认没有数据，也不在后台自动同步。需使用本人有权限的学校统一认证账号；不要求开通校园网上网服务，可通过移动热点等能访问学校系统的网络同步。

## 使用

1. 打开“课表”页，进入共用登录入口，填写学校账号与统一认证密码，选择“课表”或“两者”。
2. 同一套凭据由两条独立认证链路使用；校园网认证未通过不会阻止课表认证。已安全保存的同一账号密码可由后台复用，不返回界面。
3. 同步完成后显示当前学期课表。使用左右箭头切换周次，“回到本周”定位当前周；点击课程查看时间、地点、教师、周次、学分、类别与课程代码。
4. “同步”和“更换”都进入共用登录入口；同步失败时仍可查看原缓存。
5. “课表设置”可调整本学期开学日期，用于计算当前周次。学期固定按 20 周计算。

首次进入默认定位当前周。实践教学课程会与理论课合并显示，实践项目名称在课程详情中标注。

## 数据来源与流程

- 统一身份认证：`web.cqust.edu.cn`，密码按登录页的 `pwdEncryptSalt` 参数加密后提交，不绕过验证码。账号被要求图形验证码时同步会停止并提示，需要稍后再试。
- WebVPN 单点登录教务系统 `jwnew.cqust.edu.cn`，读取学生档案、学期日历、课表正文与培养计划；随后通过同一会话的 WebVPN 票据抓取实践教学系统 `sjjx.cqust.edu.cn` 的排课。
- 实践教学课表获取失败时保留理论课表，不影响查看。
- 课表页面结构由学校维护；学校改版后可能暂时无法解析。

## 本地数据

- 缓存文件：Windows `%APPDATA%\CQUST Wifi\schedule.json`；macOS `~/Library/Application Support/CQUST Wi-Fi/schedule.json`。
- 内容：课程名称、代码、教师、地点、实践项目、节次、周次、类别、学分、配色索引，以及姓名、院系、专业、班级、学期列表和开学日期。
- 课表缓存中不保存密码、教务 Cookie、完整认证网址或验证码。
- 是否保存共用凭据由“记住账号密码”决定；保存时使用 Windows 凭据管理器或 macOS 钥匙串，与课表 JSON 分开管理。认证密码不通过课表接口返回界面。
- 删除缓存可退出软件后删除 `schedule.json`，或在课表页重新同步覆盖。

## 范围与限制

- 仅显示当前学期；不提供历史学期切换、调课记录、提醒、日历导出或桌面微件。
- 不提供未安排时间任务列表。
- 课表数据以教务系统返回为准；同步结果中的教室、教师或周次变动取决于学校数据。
- 教务系统必须经学校网络访问。校外环境需学校 WebVPN 可用；本功能不修改系统代理。
- 课表缓存属于个人学习信息，请勿连同 `schedule.json` 或带姓名、学号的截图提交到公开 Issue。

## 验证

Rust 单元测试覆盖周次位串与区间解析、TaskActivity 相邻节次合并、实践时间与楼栋纠偏、密码加密填充、学期默认开学日期、缓存读写与校验。隔离界面检查覆盖同步表单、7 天 × 11 节课表、当前周定位、开学日期设置和课程详情；使用合成账号与课程数据，不访问真实教务账号。

另有一项按需运行的联网检查（`cargo test --bin cqust-wifi live_sync_reads_real_timetable -- --ignored`），仅在设置 `CQUST_TEST_STUDENT` 与 `CQUST_TEST_PASSWORD` 环境变量时读取真实课表用于回归，凭据不写入源码或配置。
