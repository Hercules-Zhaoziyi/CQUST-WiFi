# v5.3.0 / Android beta02 验证记录

日期：2026-10-24（Asia/Shanghai）。

## 已通过

- Windows：44 项 Rust 单元测试；2 项需要真实账号或外网的显式测试保持跳过。
- Windows 原生 WebView2：106 项界面断言，包括导航、账号、课表、Markdown 净化、代理启停、窗口吸附动画与恢复；截图仅使用虚构资料。
- Android：19 项 JVM 单元测试；Android 15 / API 35 模拟器 5 项设备测试。
- Android VPN：通过独立 UID 的测试应用验证 TUN 内 DNS 与 HTTP 流量；验证应用自身的显式 SOCKS 请求；停止后确认系统 VPN 网络消失。上游为受控测试端点，不连接真实校园账号或网站。
- 通用二维码：JSON 格式、私网地址策略、Unicode 凭据及编码／解码往返检查。
- 发布 APK：本机固定 RSA 3072 签名，apksigner 校验通过；签名私钥与密码不进入 GitHub 或 CI。
- Windows 生产程序与源码：凭据及验证后端残留扫描通过。
- 网站：320、390、768、1024、1440 像素宽度无横向溢出；亮暗主题与图库交互、下载地址、QQ/ICP备案与平台排序通过。浏览器检查没有脚本错误。

## 未完成的环境验证

- Android 17 / API 37.0：已尝试官方镜像、增大数据与内存、先行编译以及非流式安装。模拟器在安装应用前后反复出现系统 package 服务 Broken pipe，未获得有效设备测试结果，**不计为通过**。
- 本轮 Android 代码验证运行：[GitHub Actions 40014887498](https://github.com/Hercules-Zhaoziyi/CQUST-WiFi/actions/runs/40014887498)。其中 build 与 API 35 通过；API 37 安装环境失败。
- 仍需 Android 17 真机验证扫码、VPN 联网／停止、锁屏与 Wi-Fi 切换。原生库各 ABI 的 ELF LOAD 对齐均为 16384 字节，但静态对齐检查不能替代真机验证。
- 没有使用真实账号完成校园网、CAS 与课表在线同步；未自动操作真实设备的系统安装、卸载或安全确认。
- 本次未重新构建或验证 macOS 安装包，宣传页保留真实的 v5.1.1 下载。
