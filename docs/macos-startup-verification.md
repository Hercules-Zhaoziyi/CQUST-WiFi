# macOS 开机启动验证

## 无系统副作用的离线测试

此模块仅使用 Rust 标准库，可以在 Linux/macOS 上直接编译测试，不需要下载 Cargo/Tauri 依赖：

```sh
rustc --edition=2021 --test src-tauri/src/startup_macos.rs -o /tmp/cqust-startup-tests
/tmp/cqust-startup-tests
```

测试通过私有 helper 注入临时 plist 位置和虚构应用绝对路径；所有文件都位于独立临时目录并在结束时清理。测试不调用读取 HOME/current_exe 的公开入口，不写真实 LaunchAgents，不调用 launchctl，不执行应用或修改系统登录设置。

覆盖首次启用、未启用时启动、应用搬移（旧副本仍存在）、旧可执行文件消失、多次搬移和幂等修复、显式重新绑定、关闭旧启动项及重复关闭、中文/空格/XML 特殊字符、损坏/自定义启动项保护、非法路径、App Translocation、写入失败、目录和符号链接保护。

状态读取只判断文件是否与当前路径对应，不写文件。自动修复在 macOS 应用 setup 中执行一次，跳过 `--verify` 模式；失败记入应用日志，不阻止用户打开应用。自动修复只接受本项目原有格式的完整模板；自定义或其他格式的 plist 不会自动改写。用户主动开启开关可以覆盖普通文件，主动关闭可以删除普通文件；符号链接和目录会报错。

## Apple Silicon Mac 上仍需验证

离线通过不等于完成 Tauri/macOS 构建、launchd 行为、系统权限、签名或 App Translocation 的实机验证。正式分发前，在专用测试账户人工检查以下步骤（这些步骤会更改该测试账户的启动项）：

1. 构建 Apple Silicon `.app`，置于最终安装目录后打开。首次启动开关应关闭，LaunchAgent 不应凭空创建。
2. 开启开机启动，检查 plist 的 `Label`、绝对 `ProgramArguments[0]`、`--hidden` 和 `RunAtLoad`；退出登录后重新登录，确认后台启动、窗口保持隐藏、无额外实例。
3. 退出应用，移动/重命名 `.app`，从新位置手动打开。确认 plist 已绑定新路径、开关开启；再登录验证。分别保留和删除旧副本重做，并验证含中文、空格、`&` 等字符的安装目录。
4. 在旧路径失效时关闭开关，确认 plist 删除；再次启动/再次登录不应重新创建或自启。重新开启应写入新路径。
5. 在测试账户中模拟自定义或损坏 plist，确认不会被自动覆盖，日志可见失败；手动关闭再开启可恢复。模拟不可写文件/目录或符号链接，确认操作报错并保留目标内容。
6. 用实际下载的、可能被隔离的 `.app` 测试：若 current_exe 位于 AppTranslocation 目录，应拒绝绑定且保留旧文件；移动至最终目录重新打开后再设置。运行中的再次搬移需退出重开后才修复。
7. 检查 Developer ID 签名、公证后的最终安装流程与登录启动行为。Windows 开机启动实现不在本次变更范围内。

本次仅修复源码并进行离线验证，不发布正式版本。
