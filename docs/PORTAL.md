# 信息门户与统一登录

四种用途分别为校园网、课表、信息门户、全部。门户不依赖上网服务开通，也不以课表同步成功作为前提。

## Windows

`portalSignIn` 复用已有 CAS 协议，仅在校方重定向返回 `https://web.cqust.edu.cn/token-login?token=…` 时，把该地址交给系统默认浏览器。校方提升步骤由浏览器执行，应用不提前消费该地址。

检查精确域名、HTTPS、443 端口、无嵌入身份信息、固定路径、单一非空 token 参数及长度。不向前端返回登录跳转，不导出 Cookie，不把账号密码拼入 URL。若没有收到校方可交接地址则明确失败，不伪造票据。

默认浏览器接收地址不等于已证实页面登录成功；实际效果仍需真实校园账号验证。学校验证码、二次认证和服务策略保留。

## Android

非导出的 `PortalActivity` 使用独立 WebView，复制本次 CAS 认证后有效、限定网关域的 Cookie，保留 Cookie 路径和有效期并强制 Secure。拒绝文件与内容访问、混合内容和证书错误，不添加 JavaScript 接口。关闭窗口清理 WebView Cookie。

页面提供“使用浏览器打开”，外部浏览器有独立会话，不宣称与应用内状态自动同步。凭据只按用户记住密码选项保存，签名私钥仍仅本机保管。
