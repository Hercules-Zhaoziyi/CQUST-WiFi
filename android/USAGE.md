# Android 内测使用说明

## 安装与校园网登录

1. Android 10 或以上安装测试 APK，允许当前浏览器/文件管理器安装此来源的应用。
2. 在共用入口输入学号和统一认证密码，选择“校园网”“课表”或“两者”。上网认证需要先连接校园 Wi-Fi；仅看课表可使用移动数据等可用网络，无需开通校园网。
3. 可勾选保存密码；多账号入口在账号输入框右侧。切换账号前先退出当前登录。
4. 按需开启校园网自动登录与始终保持连接，并允许通知和系统后台运行。安卓端没有开机自启。

如自动探测失败，点击“认证帮助”，优先使用内嵌官方认证页读取动态跳转，也可从外部浏览器复制跳转后的完整网址。网址中可能含设备参数，请勿公开分享。

验证码会在认证帮助中显示，可点击刷新；软件不会代答或跳过验证码。

## 通过电脑代理上网

1. 在电脑 CQUST Wi-Fi 中启用“HTTP + SOCKS5”或“SOCKS5”，并允许局域网连接。Windows 防火墙需要允许相应应用/端口。
2. 手机连接可以访问电脑的 Wi-Fi；将 Android 系统 Wi-Fi 的 HTTP 代理设为“无”。
3. 安卓应用 → 代理 → 连接电脑，填入电脑显示的服务器 IP、端口和用户名。
4. 如电脑代理使用校园网密码，可在手机已保存相同校园凭据后复用；否则关闭复用并填写独立代理密码。更推荐独立密码。
5. 点击“连接并授权 VPN”，在 Android 系统确认框中同意。想停止时使用应用按钮或通知栏停止按钮。

这使用 Android VPN/TUN 将其他应用的公网流量发给电脑，不依赖其他 App 是否读取 Wi-Fi HTTP 代理。校园/私有网络和本应用仍直连 Wi-Fi。电脑地址改变时需修改配置；电脑休眠、代理关闭、网络隔离或 UDP 支持差异均可能中断连接。

“自动连接”默认关闭，仅在保存时的网关条件匹配且已授权 VPN 时尝试；它不是电脑地址自动发现，也不能保证在后台永久运行。

HTTP/SOCKS5 自身不是加密隧道，只能在可信网络中使用；HTTPS 目标内容仍由端到端 TLS 保护，应用不安装证书或解密 HTTPS。

## 本机共享

代理 → 本机共享，选择协议、端口及用户名密码后启用。默认关闭；开启后必须进行代理认证。允许局域网连接默认打开，但不会自动给系统防火墙放行。

HTTP 包含 HTTPS CONNECT；SOCKS5 包含 TCP 和 UDP ASSOCIATE。目标限公网，禁止访问本机/私网目标和 SMTP 端口，避免成为内网跳板或邮件中继。连接电脑 VPN 与本机共享不能同时启用。

## 内测边界

- beta02 起采用固定发布签名。beta01 旧 debug 签名不能覆盖迁移到 beta02，需自行卸载重装，会清除旧数据；应用不会自动卸载。之后同签名版本可应用内更新。
- Android 后台行为受品牌系统、电池策略、强行停止操作影响；请在实际校园网络测试切换 Wi-Fi、锁屏重连及长时间运行。
- 源码附有单元测试、Android 模拟器测试及依赖许可证；这些不替代真实校园网验证。
