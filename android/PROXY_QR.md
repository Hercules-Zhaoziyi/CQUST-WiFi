# 局域网代理二维码协议 v1

二维码直接承载 UTF-8 JSON，不是网址，不自动打开任何外部链接。

```json
{"type":"cqust-wifi-proxy","version":1,"protocol":"socks5","host":"172.21.1.2","port":7890,"username":"example-student","password":"example-secret"}
```

以上全部为示例值，不能用于实际认证。也兼容 `socks5://用户名:密码@私网IPv4:端口`，凭据须按 URI 规则百分号编码。

安卓验证配置类型、版本、协议、私网 IPv4、端口及非空凭据；不接受公网服务器、任意网页链接、控制字符或匿名代理。扫码后显示服务器／端口／用户名，用户确认后保存到加密凭据库，再进入系统 VPN 授权流程。

二维码含明文代理凭据，扫码预览不显示密码，不写入日志。桌面端后续实现生成时，应显著提示勿公开分享，不自动上传二维码、不加入统计或分析参数。此版本没有到期时间或签名校验，只能扫描本人可信电脑生成的配置。
