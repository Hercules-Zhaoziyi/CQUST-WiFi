# 宿主与课表的统一导航

## 单一设置入口

连接、课程表、常用网站、代理的设置入口统一进入宿主的“设置”路由。该路由调用完整课表模块 `App(settingsOnly=true)`，用组合槽接入宿主账号、连接/外观、后台权限及更新设置。课表个性化、学期、日历、提醒、上课自动化及权限子页仍由原模块导航管理。

进入设置及其子页不渲染底部主导航。返回设置根页时再返回原主页面；关于、日志使用独立返回栏。原课表主界面不再另外打开一套设置。

| 设置区域 | 数据和实现 |
| --- | --- |
| 学校账号 | `IdentityRows.kt` 合并同号、标注异号；宿主和课表凭据分开保管 |
| 连接、状态间隔、主题及动效 | 宿主 `Repository` / `Preferences` |
| 课程、学期、日历及自动化 | 课表 `SettingsRepository` / `SettingsViewModel` |
| 通知、后台、日志 | 宿主权限检测与日志页 |
| 关于与更新 | 单一宿主关于页、本机签名校验更新器 |

## 认证帮助

移除 WebView 与进程级网络绑定。`CampusEngine.discover` 复用绑定 Wi-Fi 的 HTTP 客户端、Cookie 及逐跳白名单检查，提供给登录和原生探测。帮助页只探测，不提交密码，展示未连接 Wi-Fi、探测中、已识别入口、已有会话或失败状态。

用户手动粘贴地址时继续校验官方认证域名、端口、页面及必要参数。验证码和服务选择对话框保留，不绕过认证。只展示入口主机名，不记录完整认证参数。

## 发布验证

发布私钥和密码仅在本机保管。GitHub CI 只读获取本机已签名 APK 的测试分片，核对完整 SHA-256，再在一次性模拟器中执行安装、启动与同签名覆盖升级检查。安装包不提交到源码历史，源码归档也不包含任何密钥或 APK 测试对象。
